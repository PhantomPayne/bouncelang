## How to Read This Log

- **Q numbers** are global across all iterations. A question raised in iteration 1 keeps its number if it spills into iteration 2.
- **Option letters** are local to each question. Option A for Q1 and Option A for Q2 are independent choices.
- **Scores** use the rubric from `spec-consistency-agent.md §3 Phase F`. A score of 10 means fully consistent; 0 means structurally broken.
- **Discarded option rationales** are intentionally brief (one sentence). The full tradeoff analysis is in the Phase D scoring table for that question.
- **"Known Open Issues"** at the top of this file lists everything not resolved at termination. These are the starting point for the next consistency pass.
